### Βαλκανιάδα Πληροφορικής: Προδιαγραφές Άσκησης

Στη Βαλκανιάδα Πληροφορικής που θα διεξαχθεί τις επόμενες ημέρες, συμμετέχουν 40 διαγωνιζόμενοι. Κάθε διαγωνιζόμενος παίρνει έναν **κωδικό από 1 έως και 40**, ο οποίος αντιστοιχεί στη σειρά που δήλωσε συμμετοχή. 

Κάθε διαγωνιζόμενος καλείται να επιλύσει **έξι προβλήματα**. Τα προβλήματα είναι **γλώσσες προγραμματισμού** και μπορείτε να βάλετε δικά σας ή να επιλέγεται τυχαία ονόματα από ένα σύνολο 20 ονομάτων προβλημάτων.

Για κάθε πρόβλημα αναπτύσσει τη λύση του σε μία γλώσσα προγραμματισμού και την υποβάλλει για **βαθμολόγηση**. Η **λύση βαθμολογείται σε ακέραια κλίμακα από 0 έως 100.** 

<aside>
💡

Κατά τη διάρκεια του διαγωνισμού **κάθε διαγωνιζόμενος και για κάθε πρόβλημα μπορεί να υποβάλλει τη λύση του όσες φορές θέλει**.

</aside>

**Δημιουργείστε πρόγραμμα για τη Βαλκανιάδα έτσι ώστε:**

1. (*) Να διαβάζει **επαναληπτικά** τα **ονόματα** των διαγωνιζομένων (με έλεγχο **εγκυρότητας**) και να τα καταχωρεί **σε κατάλληλη δομή δεδομένων** που συμπεριλαμβάνει όλους τους διαγωνιζόμενους.
2. (*) Κάθε φορά που μία λύση προβλήματος υποβάλλεται και βαθμολογείται, το πρόγραμμα να διαβάζει τον **κωδικό** του διαγωνιζόμενου (από 1 έως και 40), τον **αριθμό** του προβλήματος (από 1 έως και 6) και τη **βαθμολογία** του (από 0 έως και 100). 

Η βαθμολογία να καταχωρείται μόνο αν είναι **μεγαλύτερη από την προηγούμενη βαθμολογία που είναι ήδη καταχωρημένη**. Για τον τερματισμό της εισαγωγής δεδομένων το πρόγραμμα να εμφανίζει το μήνυμα **«Υπάρχει νέα λύση προβλήματος; ΝΑΙ / ΟΧΙ».** Αν εισαχθεί η τιμή «**ΟΧΙ**», να τερματίζεται η εισαγωγή δεδομένων (με έλεγχο εγκυρότητας).
3. Να υπάρχει η δυνατότητα εκτύπωσης των πληροφοριών των διαγωνιζόμενων. Η εκτύπωση των πληροφοριών κάθε διαγωνιζόμενου να περιλαμβάνει τον **κωδικό** του, τον **αριθμό** και **όνομα** του προβλήματος, τη βαθμολογία για κάθε πρόβλημα και τη **συνολική βαθμολογία** όλων των προβλημάτων.

<aside>

Κατά την εκπόνηση της εργασίας και για τις δοκιμές σας, μπορείτε τα παραπάνω δύο ζητούμενα να τα δημιουργήσετε με τυχαίο τρόπο, δηλαδή να γεμίσετε μια λίστα με αντικείμενα που το καθένα έχει: 
- σειριακό **κωδικό** διαγωνιζόμενου (1, 2, 3, …)
- τυχαίο **όνομα** και **επίθετο** διαγωνιζόμενου (Tom Robins, John Skywalker, …) [Μπορείτε να κάνετε χρήση ενός random name generator εδώ.](https://www.randomlists.com/random-names?qty=40)
- σειριακό **αριθμό** προβλήματος (1, 2, 3, …) και τυχαία  **ονόματα** 6 γλωσσών προγραμματισμού (Python, C++, Java, …)
- τυχαία βαθμολογία (0, 25, 57, 88, …)

Όταν είστε έτοιμοι με το πρόγραμμα σας, τότε υλοποιείται τα ζητούμενα της εκφώνησης.

1. Να υπολογίζει και να καταχωρεί κατάλληλα **τα αθροίσματα των βαθμολογιών κάθε διαγωνιζομένου στα έξι προβλήματα**. Για τον σκοπό αυτό να καλεί μόνο μια φορά μια **συνάρτηση** (ή μέθοδο). Δηλαδή, να αναπτύξετε **συνάρτηση** (ή μέθοδο) η οποία να δέχεται ως είσοδο μια δομή δεδομένων (π.χ. λίστα αντικειμένων - διαγωνιζόμενων) και να ενημερώνει τη συνολική βαθμολογία των επιμέρους αντικειμένων.
2. Να εμφανίζει **τα ονόματα των διαγωνιζομένων ταξινομημένων σύμφωνα με τη συνολική τους βαθμολογία σε φθίνουσα** βαθμολογική σειρά (εμφανίζει και τη βαθμολογία). Σε περίπτωση διαγωνιζομένων με την ίδια βαθμολογία, τα ονόματά τους να εμφανίζονται **με αλφαβητική σειρά.**
3. Να εμφανίζει **τα ονόματα των διαγωνιζομένων ανά κατηγορία προβλήματος και ταξινομημένων σύμφωνα με τη βαθμολογία σε αυτά σε φθίνουσα** σειρά. Σε περίπτωση διαγωνιζομένων με την ίδια βαθμολογία, τα ονόματά τους να εμφανίζονται **με αλφαβητική σειρά.**
