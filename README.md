# Entry level 1 (Java Programming)



## Ασκήσεις

Δημιουργήστε ένα πρόγραμμα το οποίο εκτελεί τα εξής βήματα και εισάγετε κατάλληλα σχόλια:

1. **Καλωσορίζει τον χρήστη.**
2. **Ζητάει από τον χρήστη να εισάγει έναν αριθμό:**
    - Εμφανίζει μήνυμα ζητώντας τον **1ο αριθμό**.
    - Διαβάζει τον αριθμό που εισήγαγε ο χρήστης.
    - Εμφανίζει μια κενή γραμμή.
    - Ενημερώνει τον χρήστη ότι ο αριθμός που εισήγαγε είναι:*π.χ. "Ο 1ος αριθμός που εισάγατε είναι ο: Χ".*
3. **Αφήνει δύο κενές γραμμές.**

**Παράδειγμα κώδικα για τα βήματα 1, 2, 3:**

```java
import java.util.Scanner;

public class Main {
	public static void main(String[] args) {
	Scanner sc = new Scanner(System.in);
	    // Βήμα 1: Καλωσόρισμα
	    System.out.println("Καλώς ήρθατε στο πρόγραμμα!");
	
	    // Βήμα 2: Ζητάμε τον 1ο αριθμό
	    System.out.print("Παρακαλώ εισάγετε τον 1ο αριθμό: ");
	    int num1 = sc.nextInt(); //διαβάζουμε τον αριθμό
	    System.out.println(); // Κενή γραμμή
	    System.out.println("Ο 1ος αριθμός που εισάγατε είναι: " + num1); // Ενημέρωση για τον αριθμό
	    
	    // Βήμα 3: Αφήνουμε 2 κενές γραμμές
	    System.out.println("\n"); // μια γραμμή λόγο του print-LN και μια γραμμή λόγο του \n 
	}
}
```

1. **Επαναλαμβάνει τα παραπάνω για τον 2ο αριθμό:**
    - Ζητάει από τον χρήστη να εισάγει τον **2ο αριθμό.**
    - Διαβάζει τον αριθμό.
    - Εμφανίζει μια κενή γραμμή.
    - Ενημερώνει τον χρήστη για τον αριθμό που εισήγαγε.
2. **Αφήνει δύο κενές γραμμές.**
3. **Επαναλαμβάνει τα παραπάνω για τον 3ο αριθμό:**
    - Ζητάει από τον χρήστη να εισάγει τον **3ο αριθμό**.
    - Διαβάζει τον αριθμό.
    - Εμφανίζει μια κενή γραμμή.
    - Ενημερώνει τον χρήστη για τον αριθμό που εισήγαγε.
4. **Αφήνει δύο κενές γραμμές.**
5. **Υπολογισμοί:**
    - Πολλαπλασιάζει  (*)  τον **1ο αριθμό** με τον **2ο αριθμό** και το **γινόμενο** το αποθηκεύει σε μια **μεταβλητή** με όνομα δικής σας επιλογής.
    - Διαιρεί  (/) το αποτέλεσμα του προηγούμενου πολλαπλασιασμού με τον **3ο αριθμό** και το **πηλίκο** το αποθηκεύει σε μια **μεταβλητή** με όνομα δικής σας επιλογής.
6. **Εμφανίζει αποτελέσματα στον χρήστη:**
    - Το γινόμενο των δύο πρώτων αριθμών: *π.χ. "Το γινόμενο των δύο πρώτων αριθμών Χ και Υ είναι: Ζ".*
    - Το προηγούμενο γινόμενο και η διαίρεσή του με τον 3ο αριθμό: *π.χ. "Το αποτέλεσμα της διαίρεσης του Ζ με τον 3ο αριθμό είναι: Α".*
7. **Ακέραιες διαιρέσεις:**
    - Υπολογίζει το υπόλοιπο της **ακέραιης διαίρεσης** (%) τπροηγούμενου γινομένου με τον 3ο αριθμό και το αποθηκεύει σε μια **μεταβλητή** με όνομα δικής σας επιλογής.
    - Αναφέρει στον χρήστη:*π.χ. "Το υπόλοιπο της ακέραιης διαίρεσης είναι: Γ".*
8. **Ενημερώνει συνολικά τον χρήστη:**
    - Αναφέρει με πλήρη λεπτομέρεια τα περιεχόμενα όλων των **μεταβλητών**:
        - Τις μεταβλητές των αριθμών
        - Το γινόμενο,
        - Το αποτέλεσμα της διαίρεσης,
        - Το υπόλοιπο της ακέραιης διαίρεσης.

### **Οδηγίες για τον κώδικα:**

1. Στην αρχή του κώδικα, εισάγετε:
    
    ```java
    import java.util.Scanner;
    ```
    
2. Στο τέλος της μεθόδου `main`, εισάγετε:
    
    ```java
    sc.**close**();
    ```
